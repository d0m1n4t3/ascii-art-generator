# ASCII Art Generator

A fun and simple Python command-line tool to convert images into ASCII art.

## Features
- Convert any image to ASCII art
- Adjustable width and detail
- Works with most image formats

## Requirements
- Python 3.x
- Pillow (Python Imaging Library)

## Installation
```bash
pip install -r requirements.txt
```

## Usage
```bash
python ascii_art.py image.jpg --width 100
```
